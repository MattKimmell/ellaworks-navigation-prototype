# Ellaworks navigation prototype

Static, interactive product-design review using sample data. All edits, conversations,
connections, tests and deployments are browser-local simulations.

- Open the prototype at the repository’s GitHub Pages URL.
- Open `navigation-summary.html` for the navigation proposal.
- Download `ellaworks-navigation-review.html` to share the summary as a standalone file.

Live-app screenshots, internal handoff documents and source application code are
not included. Published assets were built from the local review prototype.
