1. Proposed structure

Four work areas in v3. Existing capabilities are regrouped; new experiences are identified below.

Chat

New experience

Work with agents and teams.

  • Team selector → Conversations and Missions
  • Lead responds by default; @ another agent to address them.
  • People and Team tools open when needed. External customer/supplier agents are labeled separately from team members.
  • Demo: Rush coordinates a service estimate, Artur approval and invoice handoff. Two Artur work orders and a separate PACCAR Parts sourcing case keep messages, approvals and missions separate.

Manage

Existing capabilities + revised layouts

Build, configure, test and operate agents.

Resources

Existing capabilities, regrouped

Manage reusable knowledge, prompts and tools.

  • Prompts

  • Tools
  • Registries

Elladex

Existing service, new entry point

Discover and submit agents.

  • Discover
  • Entry to the existing Elladex service.
How navigation works: the bottom-left switcher selects Chat, Manage, Resources or Elladex. Chat has a focused conversation sidebar. Manage uses fixed headings and page tabs. Resources has its own sidebar. Personal account and organization controls remain separate from team settings.

Team controls stay with the team

Team tools links to the existing Inbox, Task Board and Activity pages in Manage. Team settings opens an overlay with General, Policies, External agents and App connections; Open in Manage opens the same configuration. Connections, policies and approved external agents apply to the selected team.

One team, connected surfaces

Chat and Manage share the team’s configuration. Existing team creation still sets the team’s purpose. In the new Chat experience, “Track as a mission” adds a goal, completion criteria and status to a request within a conversation. External exchanges expand within it and identify the shared context. Resources links show which agents or teams use each item.
